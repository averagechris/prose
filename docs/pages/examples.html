prose examples

prose stores user-owned material and approval evidence; it does not call a model or embed built-in verbs. The separate starter data is imported explicitly.

prose --json pack import --file packs/starter.json --activate
prose --json pack create --file personal-pack.json
prose --json pack use personal
prose --json context reviews
prose --json verb tighten
prose --json surface github-pr
prose --json draft create --file draft.json
prose --json draft append review-42 --parent 1 --content-file revised.txt
prose --json attest --file approvals.json

Pack verbs declare a transform-selection or draft-from-intent family, instructions, context bindings, and typed length/no-new-claims/preserve-meaning constraints. Drafts freeze exact pack revisions. Approval files identify the human, harness and session, method, exact draft versions, and per-item exceptions in one atomic bulk event.
